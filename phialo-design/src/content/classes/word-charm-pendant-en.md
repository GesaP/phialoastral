# Blender 3D Mini: Make a Word Charm Pendant

Create a personalized word charm pendant in Blender and prepare it for 3D printing.

## What You'll Learn

This compact project class walks you through the essentials of building a custom text-based charm in Blender, adding structure for a wearable pendant, and preparing the design for export.

## Course Highlights

- Create 3D text in Blender
- Build a pendant backing and bail
- Use boolean operations for engraving and cutouts
- Check the model for 3D printing
- Export the finished charm as an STL file

## Who This Course Is For

- Beginners looking for a focused Blender jewelry project
- Designers interested in personalized pendants
- Makers who want to create printable word charms
- Anyone curious about turning text into wearable 3D designs
