# Prompt to Print - Use AI & Blender 3D to Create Your Dream Design

Turn an AI prompt, sketch, or image into a 3D model, a polished render, and a print-ready file.

## What You'll Learn

This class shows a streamlined prompt-to-3D workflow: developing a clear concept, converting an image into a 3D model, cleaning it up in Blender, creating a refined render, and preparing the file for 3D printing.

## Course Highlights

- Prompt for strong forms and silhouettes
- Compare AI image and 3D generation options
- Bring generated 3D models into Blender
- Set up materials, lighting, and a turntable render
- Prepare a model for slicing and 3D printing

## Who This Course Is For

- Curious beginners and intermediate 3D artists
- Jewelry, miniature, and sculpture makers
- Artists who want physical results from digital ideas
- Blender users exploring AI-assisted workflows
